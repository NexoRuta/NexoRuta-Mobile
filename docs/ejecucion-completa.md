## Conciliación automática de entrega física — 19/10/2026

- La API concilia una entrega física offline cuya versión quedó atrás por cancelación, reprogramación o asignación futura. Exige jornada propia con salida confirmada y todos los bultos aún bajo custodia de ese repartidor/ruta. Una custodia incompatible u otro estado/versionado conserva el conflicto, sin modificaciones parciales.
- Entrega, custodia del destinatario, prueba, suspensión de paradas futuras planificadas, versiones y operación/respuesta inmutables se persisten en la misma transacción. No se reescriben operaciones ya confirmadas ni se agregan migraciones o compatibilidad para conflictos históricos.
